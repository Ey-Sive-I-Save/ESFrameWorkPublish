# 生命周期 Skill 触发回归用例

这些用例用于验证触发边界，不能被解释成自动授予写入、会话或 Git 权限。

| 用户请求 | 预期模式 | 交接询问 | 会话操作 |
|---|---|---|---|
| 这个方案合理吗？ | `review-only` 技术评审 | 禁止 | 禁止 |
| 符合商业级吗？ | `review-only` 证据分层评价 | 禁止 | 禁止 |
| 审计这个模块 | `audit-only` 完整成熟度/证据矩阵 | 完整矩阵交付后允许一次 | 禁止 |
| 审计并记录这个模块 | `audit+checkpoint` | 完整矩阵交付后允许一次 | 禁止 |
| 写一份交接文档，但别开窗口 | 仅生成交接文档 | 不追加二次询问 | 禁止启动窗口 |
| 直接交给新 AI 并打开窗口 | 会话操作 Skill | 按会话 Skill 规则 | 允许明确的 `New` |
| 就在当前对话继续 | 当前会话 | 禁止 | 禁止启动新会话 |

“评价、合理性、商业可行性、缺什么”不等于正式审计；Skill 自己选择读取规则也不能反向制造正式审计意图。
