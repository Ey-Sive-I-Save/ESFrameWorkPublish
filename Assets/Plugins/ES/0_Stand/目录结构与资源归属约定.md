# ES 0_Stand 目录结构与资源归属约定

> 状态：现行约束
>
> 适用范围：`Assets/Plugins/ES/0_Stand`

## 目的

`0_Stand` 是 ESFramework 基础层。为了避免运行时代码、内部资源、公开示例和生成产物互相混放，新增文件必须先按职责选择目录。

## 目录职责

### `_Res`

`_Res` 只承载资源系统本身的实现代码和固定源码分层：

- `Bootstrap`：资源系统启动代码与 Bootstrap 运行时桥接；
- `Master`：资源库、Book/Page、Manifest 等资源主链实现；
- `ResUse`：资源引用与资源使用 API；
- `Runtime`：运行时加载器、Provider、Scope、AssetTable 等运行时实现。

不要在 `_Res` 根下新增 Shader、材质、Prefab、场景、贴图、音频或公开示例。除非已有资源系统源码明确要求，否则不要新建第二套 `_Res` 资源目录。

### `InternalAssets`

`InternalAssets` 用于 ES 自身运行、编辑器展示和内部验证所需的非公开资源：

- `Shaders`：ES 自有 Shader、HLSL 和 Shader 参数入口；
- `ResourceBootstrap`：ES 内置 Bootstrap 场景、主题等内部资源；
- `ShaderExamples/Materials`：用于查看 Inspector、中文分组、质量档位和效果组合的案例材质。

如果后续增加 ES 内部 Prefab、纹理、测试场景或演示资源，优先在 `InternalAssets` 下按职责新建子目录，不要直接放到 `_Res` 根目录。

### `3_Examples`

公开给开发者阅读、复制或运行的示例代码和示例资产统一放在 `Assets/Plugins/ES/3_Examples`，按基础、运行时、编辑器和数据等现有分类归档。

示例脚本不得因为依赖资源系统就放进 `_Res`。例如 `ESAssetRefer` 的用法示例属于 `3_Examples/1_Runtime/Example_Res`。

### `BaseDefine_RunTime/ShaderSystem`

Shader 参数枚举、Property ID 和 PropertyBlock 稳定入口属于基础运行时代码，不属于资源目录。相关 C# API 放在这里；Shader/HLSL 源文件仍放在 `InternalAssets/Shaders`。

### `Tests`

测试代码和测试资产统一放在 `Tests`：

- `Dialog`、`ValueChange` 等已有目录：独立测试程序集；
- `TestAssets/ResourcePipeline`：资源管线测试库使用的 Unity 测试资产。

测试资产不得放回 `_Res` 或 `InternalAssets`，也不要使用没有测试语义的临时根目录名。迁移测试资产时必须同步测试库中的 `AssetPath`，并保留 `.meta` GUID。

### 生成与恢复产物

资源烘焙、构建、恢复和输出产物不放入 `0_Stand` 源码目录：

- `ES/ResourcePipeline/Baked`：烘焙与恢复快照；
- `ES/Automation/Output`：自动化输出和诊断日志；
- `ES/Automation/Candidates`：待审阅候选产物；
- `ES/Bak`：按项目规则管理的备份。

这些目录中的旧路径快照不能手工冒充当前资源路径。资源路径发生迁移后，应通过对应的资源烘焙或生成流程更新，而不是直接批量改写历史产物。

## 路径迁移规则

1. Unity 资产迁移必须保留原 `.meta` GUID。
2. 资产库、项目资产指南或其他作者配置中的路径字段必须同步更新。
3. 运行时源码、Manifest/Table 和资源加载契约不得因为目录整理而新增旁路。
4. 迁移后必须搜索旧路径引用，并区分当前作者配置、源码引用、生成快照和历史文档。
5. 生成快照、恢复目录和历史记录默认只读，不在目录整理时直接改写。
6. 文本修改使用 UTF-8；完成后执行严格 UTF-8 检查和 `git diff --check`。

## 快速判断

| 文件类型/用途 | 首选目录 |
| --- | --- |
| 资源系统 C# 实现 | `_Res` 对应源码子目录 |
| ES 内部 Shader/HLSL | `InternalAssets/Shaders` |
| Shader 参数枚举、Property ID、PropertyBlock API | `BaseDefine_RunTime/ShaderSystem` |
| ES 内置场景、主题 | `InternalAssets/ResourceBootstrap` |
| Shader 案例材质 | `InternalAssets/ShaderExamples/Materials` |
| 面向开发者的资源示例 | `3_Examples/1_Runtime/Example_Res` 或对应示例分类 |
| 资源管线测试资产 | `Tests/TestAssets/ResourcePipeline` |
| 烘焙、恢复、自动化输出 | `ES/ResourcePipeline` 或 `ES/Automation` |
