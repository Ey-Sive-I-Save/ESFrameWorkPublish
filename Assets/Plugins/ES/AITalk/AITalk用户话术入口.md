# AITalk 用户话术入口

用户不需要知道 Session、Messages、pollPolicy、Hash、TaskContract 或其它专业字段。只要使用下面几种话术，主 AI 会自动补齐内部步骤；如果缺少真正必要的信息，只追问一件事。

## 五句就够

| 用户说 | AITalk 做什么 | 用户下一步会看到什么 |
|---|---|---|
| **开始 AITalk：讨论 <主题>** | 创建或选择 Session，准备参与者和权限 | 返回会话主题、参与者和“还缺谁” |
| **继续 AITalk：<主题>** | 读取当前 Session 全部新增消息并继续轮询 | 返回当前阶段和下一轮等待事项 |
| **汇总 AITalk：<主题>** | 聚合消息、隔离冲突并生成候选共识 | 返回已达成、分歧、风险和待确认项 |
| **暂停 AITalk：<主题>** | 停止本轮自动推进，保留可恢复状态 | 返回暂停原因和恢复话术 |
| **结束 AITalk：<主题>** | 检查结束条件并生成最终候选结论 | 返回结论或明确说明还缺什么 |

## 最短可用示例

```text
开始 AITalk：帮我评审玩家控制架构，邀请架构 AI 一起讨论。
```

```text
继续 AITalk：玩家控制架构。
```

```text
汇总 AITalk：玩家控制架构。
```

```text
暂停 AITalk：玩家控制架构。
```

```text
结束 AITalk：玩家控制架构。
```

## 系统会自动处理的事情

1. 创建独立 Session，并写入会话说明和参与者清单。
2. 自动使用项目绝对路径，不要求用户复制路径。
3. 自动按会话规则轮询新消息；默认 15-30 秒、最多 5 轮。
4. 自动聚合、去重、隔离冲突和过时绑定。
5. 自动告诉用户“当前阶段、还缺什么、下一句该说什么”。
6. 只在明确结束或用户拍板时停止；沉默只表示等待。

## 系统只会追问一件事

如果话术缺少主题，系统只问：

```text
你想让 AITalk 讨论什么主题？用一句话描述即可。
```

系统不会要求用户填写：

```text
SessionPath、Messages 路径、taskBinding、routePlanHash、sourceScopeHash、轮询秒数、Hash 或 JSON。
```

## 明确边界

- 话术是用户意图入口，不是权限授予器。
- “开始”不等于允许改代码；代码范围仍由用户当前指令和会话说明决定。
- “汇总”只生成候选结果，不等于任务完成。
- “结束”不会把沉默伪装成共识；条件不满足时会明确返回缺口。
- AITalk 只负责对话、轮询、批次编排和结果聚合；执行动作仍需走对应受管合同。
