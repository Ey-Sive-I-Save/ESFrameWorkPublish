# 已废止：旧 ESGameTag 源码说明

最后核对：2026-08-02。

本文件原先描述 `ESTagRefCountSet64`、`AddGameTag`、`RemoveGameTag` 与 Entity 专属持有模型。该模型已经废止，不能作为任何新代码、配置、迁移或验收的依据。

当前唯一现行规则见：

```text
AIWarnings/10_P0最高约束（P0Guardrails）/总体架构（Architecture）/
项目最高警告_Codex核心上下文总纲_状态机IK标签调度LOD_AI协作警告.md
```

摘要：

- `ESTagCollection` 是通用事实容器；Entity 与 Item 均可按需成为 Host。
- Host 自身事实使用幂等 `SetTag`；外部生命周期使用 `ESTagLease` 或 `ESTagLeaseSet`。
- 运行时身份来自 GameCore Tag Catalog，Hot/Sparse 只是存储策略。
- Count/Presence 只通过 `ESTagCollection` Link 派发；不得恢复第二套 Tag C# event。
- 旧 `AddGameTag/RemoveGameTag` 和旧容器不再是业务 API。

保留此文件名仅为阻止旧路径被重新创建；不得在其后补写旧方案或把它恢复为现行设计说明。
