## 提案边界（阶段 A 部分实现，未完成真实验收）
- 业务只引用 AudioCue，经 ESAudioModule 进入 Unity 或 FMOD 后端；ResourcePlan/Provider/Release Manifest 是唯一资源真相源，Bank 不得伪装为 AssetBundle/CodePackage 或旁路 URL 下载。
- Cue 烘焙为 Unity Clip 或 FMOD Bank Participant；Voice、Emitter、Plan/Scope 和 Provider 重建必须拥有独立且可证明的生命周期，旧回调不得写回新代际。
- 阶段 A/B/C 分别覆盖 Unity 后端、签名 Runtime Payload 和 FMOD 原生后端；每阶段必须声明授权、取消、回滚、证据等级和失败边界。
- P1-P12 运行验收、调用点迁移、发布回退、IL2CPP 与 FMOD Bank 校验尚未完成；不得把静态设计或单次播放写成 Runtime/Profiler/Player/IL2CPP/发布通过。

详细架构、生命周期不变量、发布接入、调用点迁移、P1-P12 验收矩阵与风险决策见 Knowledge。
