# ResourceV1 Obsolete

This folder contains the retired ESResMaster / ESResLoader / ESResSource / ESResTable resource chain and its supporting V1 DTOs and helpers.

The supported resource path is the newer Catalog / Manifest / RuntimeMap / Provider / Scope / Lease chain under `0_Stand/_Res`.

Files are retained here temporarily with their original `.meta` GUIDs for migration audit and recovery. Do not add new runtime or editor dependencies to this folder.
