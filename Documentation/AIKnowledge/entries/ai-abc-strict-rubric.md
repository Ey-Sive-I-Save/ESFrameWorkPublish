# ABCD 三模式严苛评分基线

权威合同：`ES/Automation/Contracts/es-ai-abc-scoring-v1.json`。

三种模式均使用 0～5（允许小数）等级，先按模式独立判级，再映射到统一分数：

`0→-20，1→0，2→20，3→40，4→70，5→90`，锚点之间分段线性插值。

评分只计算相对目标的增量收益；原版已经具备的思维深度、循环和表达不能计为新增创新。创新、工程、稳定各自使用合同中的六级锚点，基础层与 ABCP 扩展层同样受 0～5 等级、证据和回归约束。

每个候选至少执行三代连续深度分叉。每一代必须记录决定、连续后果、错误累积、与原版或庸俗基线的逐维差异。差异不足时对应维度归零，不得由平均分掩盖。

静态评分不证明 Unity、玩家、网络或发布行为；必须分别标记 `Static-Reasoning` 与 Runtime/Player 证据。
