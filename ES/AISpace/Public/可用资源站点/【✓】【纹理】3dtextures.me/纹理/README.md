# 3DTextures.me 纹理样本

来源：<https://3dtextures.me/>（站点首页及 2026 年纹理文章公开图片链接）。本批下载 10 个 PNG 纹理缩略图，总量 3,116,453 bytes（≤10 MB）。下载文件先在临时 staging 目录打包、解包至 `textures/`，随后删除 ZIP 与 staging；当前无压缩包残留。未运行 Unity/Hooks。

逐文件 SHA-256 与字节数见 `hashes.json`。图片经 CDN `i0.wp.com` 的 `resize=256` 参数获取，仅作可见资源样本，不代表原始 PBR 全分辨率材质包。
