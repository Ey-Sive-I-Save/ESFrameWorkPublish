## 1. 我实际修改的编辑器能力

### RuntimeWatch / SimpleTools

- 重排 RuntimeWatch 页面为“范围与刷新 → 规则 → 结果 → 操作 → 证据 → 诊断”。
- 把采样从 OnGUI/Layout/Repaint 移到受控刷新路径，增加 `entries` / `renderEntries` 分离，处理 Layout/Repaint 控件树错位。
- 增加前台焦点门禁、范围切换刷新、读取失败/慢读取/最近变化筛选、操作反馈和窄窗口布局。
- 收紧 ObjectPool、Asset、Scene 等 SimpleTools 的公共标题、状态、主操作和风险提示。
- 修正 ObjectPool 快照绘制导致的 GUILayout 崩溃方向，并保留低分配约束。

### ES 编辑器绘制与案例

- 推进 `ESEditorSection` / `ESEditorSectionNavigator` 的分区导航、连续绘制和 Section Processor 规则。
- 修正 Odin 分组缺失、Begin/End Section 与 Button/Group 冲突等问题。
- 推进 `ESPolymorphicReferenceDrawer`、`ESTypeCatalog`、多目标编辑、缺失类型、Undo、清除和重选类型流程。
- 增加 ES Presentation 的 `ESFieldRow`、状态表达、编辑器主题/健康检查入口和多态边界案例。
- 为常见案例、RuntimeWatch、ItemMotion、资源流程和多目标边界对象接入 `ESReadMeNote`。

### GameCore 属性配置

- 收紧角色/物品属性表的列宽和字段顺序。
- 隐藏暂不支持的公式字段，但保留旧数据 Bake 拒绝校验。
- 明确普通属性修改直接 Bake，只有固定访问名或身份结构变化才生成固定 API。

## 2. 我实际补写和修正的 AIWarnings

- 资源加载：Resident、Owner Scope、TemporaryScope、`LoadAsyncLease`、ReferenceCount/LeaseCount、generation、安全点和 Provider 切换。
- Raw 资源：`TextAsset/.bytes` 载体、Catalog/Bundle/Consumer/缓存复用和禁止平行下载器。
- `ESContentResourceBinding`：baked Consumer ID、ActivePlan、ExitTransitionPlan 和离开后缓存保留。
- Consumer/Library 增量激活：串行 Gate、active 集合、成功后登记、失败可重试。
- ResourcePlan Runtime Extension：Context 只能读取当前 Plan 已加载资产，Lease 逆序释放，异常/取消/Dispose 清理；明确 Publish Extension 尚未存在。
- GameManager：`TryGetModule` / `GetOrCreateModule` 和 `ESGameSave` 查询/创建语义。
- Contextitecture、ESCommand Runner、Interactable 生命周期、PropertyTree 多目标与迁移、GraphView/NodeRunner 阻断边界。
- 新增 P0：`SoDataInfo` 必须对应 `SoDataGroup<TInfo>`，正式 Info 必须有唯一主 Group，`SoDataPack<TInfo>` 默认冻结。
- 增加 Temporary Lease T1～T7 验收矩阵。
- 修正 AIWarnings 当前状态矩阵，避免把源码存在、工程收录、dotnet 编译、Unity/Player 验收混写。
