# Level Data Archive

`LevelDataInfo`, `LevelDataGroup`, and `LevelDataPack` were an unfinished
legacy level-data model. The active framework has no authoritative Level
lifecycle or resource contract, so this model is intentionally excluded from
Unity and project compilation.

The original sources are retained here for historical reference only. Do not
move them back into `Assets` without first defining the owning gameplay
lifecycle and migration path for the existing serialized level-pack assets.
