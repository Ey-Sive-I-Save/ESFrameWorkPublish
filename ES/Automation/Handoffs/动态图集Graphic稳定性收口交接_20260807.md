## 已确认的必须修正项

### 1. OnValidate 基类生命周期

文件：

`Assets/Scripts/ESLogic/Runtime/Graphics/DynamicAtlas/ESDynamicAtlasGraphic.cs:217`

当前为：

```csharp
private new void OnValidate()
```

Unity 2022.3.45f1 的 `Graphic.OnValidate()` 与 `MaskableGraphic.OnValidate()` 均为 `protected override`。当前写法跳过基类链，可能遗漏 Stencil、Mask、Clip Parent 与完整 Dirty 更新。

应使用 `protected override void OnValidate()` 并先调用 `base.OnValidate()`。基类已经执行 Dirty 更新，额外的 `SetVerticesDirty()` / `SetMaterialDirty()` 只在确有额外语义时保留。

### 2. 自定义材质所有权

相关位置：

- `ESDynamicAtlasGraphic.cs:111` 的 `Clear()` 会执行 `material = null`。
- `ESDynamicAtlasGraphic.cs:309` 的 `RefreshMaterialMode()` 会在默认材质与预乘材质之间覆盖 `material`。

建议建立显式材质模式：

```text
Auto
StraightAlpha
PremultipliedAlpha
Custom
```

Custom 模式下，Bind、Page Lost、Provider Transition、Clear、OnDisable/OnEnable 均不得静默覆盖用户材质。Auto 模式根据 `ESDynamicAtlasAlphaMode` 选择默认或内置预乘材质。

### 3. Sprite 编辑器预览边界

文件：`ESDynamicAtlasGraphic.cs:277`

当前直接读取 `editorPreviewSprite.textureRect` 并始终生成四边形。风险包括 Tight Mesh 异常、SpriteAtlas 旋转打包、不规则 Mesh 和不准确 UV。

最低门禁：捕获 `textureRect` 访问异常并安全回退，不影响 Inspector 和 SceneView。

若承诺 Image 级精确预览：使用 Sprite 的 vertices、triangles、uv 生成编辑器预览 Mesh，并按 Sprite 变化缓存/失效，避免重复分配。

## 额外发现的稳定门禁

### 非 PlayMode 请求隔离不完整

`OnEnable()` 和 Inspector 自动加载有 `Application.isPlaying` 门禁，但公开 `SetAsync()` / `CopyAsync()` 没有。编辑器脚本仍可能直接初始化动态图集模块并进入资源加载。需要明确拒绝、抛出可诊断错误或建立受控 Editor-only 路径。

### Verifying 模块默认自动激活

`Assets/Scripts/ESLogic/Runtime/GameManager/-GameManager_Core/ESGameManager.cs:52`

`autoCreateDynamicAtlasModule = true`，并在 Awake 自动创建模块。稳定前必须明确决定：暂时默认关闭，或在取得完整验收后保留默认开启。不得让未稳定模块无说明地渗透所有 GameManager 实例。

## 性能收口

`ESDynamicAtlasRuntime.Tick()` 每帧调用 `EvictUnusedEntries()`，当前每次创建 `new List<Entry>()`。还存在：

- Lease 释放时 `RemoveObservationsForLease()` 创建 `new List<long>()`；
- 上传路径创建 `MaterialPropertyBlock`；
- Cache pressure 候选列表临时分配；
- Snapshot 创建完整 Page/Entry 列表并复制全部条目；
- 百分位统计每次复制并排序样本；
- 上传样本满 256 后使用 `RemoveAt(0)`。

监视器不是每帧 Snapshot，而是窗口打开且自动刷新时每 0.25 秒完整复制一次。对 2000 条目仍应增加 summary-only、分页/上限或复用缓冲。

建议加入 ProfilerMarker：Tick、Allocate、Upload、Fence、Evict、Notify、Snapshot。
