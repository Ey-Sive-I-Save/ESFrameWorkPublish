# TaskContextRuntime v1 Risk Register

| Risk | Prevention | Detection | Isolation / recovery | Static acceptance |
|---|---|---|---|---|
| stale concurrent writer | TaskRevision + ContextVersion CAS and per-task mutex | CAS conflict test | reload current state and retry with a new idempotency key | stale writer cannot append |
| partial completion commit | Receipt is create-only and event binding is authoritative | orphan Receipt count | ignore orphan; retry completion at current revision | orphan never changes state |
| Receipt or event tamper | canonical SHA-256 chain and binding checks | integrity validator | quarantine task store; preserve bytes | tamper reports failed |
| source drift after evidence | rehash verified sourceScope before completion | drift test | `PartiallyInvalidated`, reverify, resubmit evidence | accepted is impossible while drift exists |
| Worker/Skill self-acceptance | platform computes hashes and decision | schema/API review | reject direct lifecycle writes | candidate evidence alone is non-authoritative |
| delivery rejection rollback | separate delivery axis | delivery rejection test | feedback or explicit Reopen | completion Receipt remains valid |
| path escape | project-relative resolution and descendant reparse-point rejection | traversal and junction tests | reject before event write | no out-of-root source read or store write |
| interrupted retry duplication | create-only files and operation-fingerprint-bound idempotency lookup | exact-repeat, cross-operation reuse, and recovery tests | return only the matching original event state | no duplicate revision and no cross-action key reuse |
| quarantine recovery trap | persist the exact prior non-quarantined ContextStatus in both transition metadata records | archived and partially-invalidated recovery tests | restore the recorded state without guessing from TaskStatus | every admitted Quarantine has a compatible Recover path |
| existing Automation semantic collision | adapter-only boundary and explicit non-equivalence | route/API review | retain current Automation status | no enum projection |
| optional integration leaks into Core acceptance | stable prohibited/conditional capability IDs and profile-scoped `requiredCapabilityIds` | integration policy validator plus four mutation-negative cases | reject the validator/profile change; restore empty Core requirements and explicit Runtime/Release selection | unselected AIBrain, Facade, Worker, Session, Archive, Unity, Runtime, and Release gaps cannot block StaticReview or EngineeringReadiness |
| advisory endpoint registration failure cascades | isolate `ESTaskContextEvaluationAutomation.Register()` from later endpoint registration | source boundary assertion; Unity registration remains pending | disable only `/eval`, preserve other endpoints, report stable isolation code | local registration fault cannot abort unrelated endpoint setup |
| Worker output scope expansion | Worker independently requires `ES/Automation/Runs/TaskContextEvaluation/<N-format runId>/request.json` | out-of-scope process negative | reject before producing `result.json` | direct Worker invocation cannot write another project subtree |
| transport result forges platform evaluation | validate run/task/worker/input/output identities and hashes; reject Automation CompletionDecision | CAS, completion injection, hash drift, and managed-result source negatives | fail the Automation Run without mutating TaskContext lifecycle | transport status cannot become evaluation authority |
| source registration overclaimed as Runtime | separate source, Unity registration, and production-execution flags | adapter Schema rejects ambiguous legacy flag and Runtime overclaim | retain `runtime-not-run`; require Unity-hosted receipt for upgrade | static registration cannot claim Runtime or Release |
| correctly hashed but semantically forged RoutePlan | freeze routeKeys and replay exact stage/Profile/route/depth registry membership through one shared canonical module | real-artifact negative matrix covers unregistered stage, Profile/route mismatch, missing directional depth authorization, missing Goal/Registry SourceRef, forged hash, and drift | reject before task creation; during completion return task-scoped `undetermined` with RoutePlanDrift | no forged or stale RoutePlan can issue an accepted Receipt, and no RoutePlan error expands to project-global P0 |

Change budget: one new platform directory, one schema, intent contract, and integration acceptance policy, one new direct-child Skill, and only the necessary discovery/Knowledge records. No Git, Unity/Worker Runtime, network, release, history, audit-state, deletion, or rename action is in scope.
